# Mental Burnout Detection System

An AI-based multimodal system developed to assess possible signs of mental burnout using multiple behavioral and emotional inputs. The system collects questionnaire responses, facial expressions through a webcam, voice responses, and iris movement data, then analyzes these signals using AI, machine learning, speech processing, and computer vision techniques. It identifies facial emotions, analyzes voice patterns, tracks eye movements, calculates a stress score, estimates mind age, and provides personalized recommendations using the Gemini API. The application is built with Flask and integrates DeepFace, Wav2Vec 2.0, MediaPipe, OpenCV, TensorFlow, and Scikit-learn.

**Tech Stack:** Python, Flask, DeepFace, Wav2Vec 2.0, MediaPipe, OpenCV, TensorFlow, Scikit-learn, Gemini API, HTML, CSS, JavaScript.
